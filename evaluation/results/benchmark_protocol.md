# Three-way benchmark protocol

The protocol uses the published UNSW-NB15 labeled flow file documented at [the UNSW dataset page][1]. The accessible file is partitioned deterministically and disjointly by `id % 10`: buckets 0–5 are training, 6–7 validation, and 8–9 test. Only benign training rows fit the `RobustScaler` and `IsolationForest`; validation is used once for threshold selection and test is held out for final measurement.

| Partition | Records | Benign | Malicious |
|---|---:|---:|---:|
| Train | 49,400 | 22,202 | 27,198 |
| Validation | 16,466 | 7,400 | 9,066 |
| Test | 16,466 | 7,398 | 9,068 |

## Threshold-selected ML result

The threshold was selected by maximizing validation F1 over 199 score quantiles. The final held-out test result was:

| Metric | Validation | Test |
|---|---:|---:|
| Accuracy | 70.8794% | **70.7519%** |
| Precision | 70.1519% | **69.9887%** |
| Recall | 81.9987% | **82.0909%** |
| F1 | 75.6141% | **75.5583%** |
| FPR | 42.7432% | **43.1468%** |
| FNR | 18.0013% | **17.9091%** |

Test confusion matrix: **TN 4,206; FP 3,192; FN 1,624; TP 7,444**.

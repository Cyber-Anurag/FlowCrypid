# Real sample.pcap demonstration

This directory contains a valid libpcap file, `sample.pcap`, generated by `scripts/create_sample_pcap.py`, and the captured API result in `sample_analysis_result.json`.

Run the demonstration from the repository root:

```bash
PYTHONPATH=. python3 scripts/demo_sample_pcap.py
```

The demonstration uses the same authenticated upload endpoint as the dashboard. The observed pipeline is:

| Stage | Observed result |
|---|---|
| Upload | `POST /api/upload` accepted `sample.pcap` with HTTP 202 and returned a background job ID. |
| Parse packets | 13 packets parsed from the PCAP; 0 unsupported packets. |
| Build flows | 2 flows built: one DNS/UDP flow and one large TCP transfer flow. |
| Extract features | Canonical feature extraction executed for each flow, including DNS label entropy for `a1b2c3.example.com`. |
| Run detectors | `FLOW-ENSEMBLE` and persisted `ML-ISOLATION-FOREST` both produced detector output. |
| Risk scoring | Returned risk scores of 72 and 50 in the API findings. |
| Finding | 2 findings returned, including an `Isolation Forest flow anomaly`. |
| Dashboard | The `dashboard_payload` object is the JSON response consumed by the frontend findings view. |

The generated sample contains a real DNS query and a repeated 12-packet, approximately 720 KB TCP transfer to an external address. It is a deterministic demonstration fixture, not a claim about real-world maliciousness or model performance. The full machine-readable result is in `sample_analysis_result.json`.
